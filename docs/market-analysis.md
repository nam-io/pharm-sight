# 시장 분석 및 경쟁 제품 분석

> PharmSight AI의 시장 기회, 경쟁 제품 분석, 사용자 검증 근거를 정리한 문서입니다.

---

## 1. 문제 정의 — 약국 경영 데이터 사각지대

### 시장 배경

- 국내 지역 약국: **약 25,000개** (건강보험심사평가원, 2024)
- 전체의 85% 이상이 1인 또는 소규모 운영 약국
- 약국 1개당 하루 평균 조제 건수: 100~200건 이상
- 월 매출 규모: 소형 1,000만~3,000만원, 중형 3,000만~7,000만원

### 생존 위협: 약국 폐업률 증가와 체인 경쟁

- **매년 약 1,000개 이상의 약국이 폐업** (대한약사회 통계 기반 추정)
- 올리브영 등 대형 드러그스토어·체인 약국이 POS 데이터 분석으로 재고·마케팅을 최적화하는 반면, 개인 약국의 85%는 여전히 감(感)에 의존
- 코로나 이후 비대면 처방 확대, 배달약국 서비스 등 새로운 채널 증가 → 데이터 관리 복잡성 폭증, 기존 수작업 한계 도달
- **데이터 분석 능력의 유무가 개인 약국의 생존 경쟁력으로 직결**되는 시대

### 핵심 문제: 3개 데이터 시스템 파편화

```
[처방·조제] ←─────────────────────────────────────────────────── [통합 불가]
  비*소프트 / 유*케어 (건보 청구 목적)

[OTC 판매] ──────────────────────────────────────────────────── [연계 없음]
  POS 단말기 / 수기

[도매 발주] ──────────────────────────────────────────────────── [연계 없음]
  지오영 앱 / 전화 주문
```

**결과:** 약국 경영자는 세 데이터를 합산해 본 적이 없으며, 순이익률·병원 의존도·약품군 수익성을 정확히 모른 채 경영하고 있음.

## 2. 사용자 검증 (User Validation)

### 실제 약사 인터뷰 (2026년 3월, 3인)

**인터뷰 대상:**
- A약사: 서울 마포구, 소아과 인근 개인 약국, 경력 8년
- B약사: 경기 수원, 내과·이비인후과 복합상권, 경력 5년 (개국 2년차)
- C약사: 인천 남동구, 주택가 약국, 경력 12년

**인터뷰 핵심 발췌:**

| 질문 | 응답 요약 |
|------|----------|
| 현재 경영 데이터 어떻게 관리하십니까? | "청구 프로그램이랑 엑셀 두 개 씁니다. 근데 합치는 건 포기했어요." (A) |
| 월별 순이익률을 파악하고 있습니까? | "대략 압니다. 정확하게는 모르죠. 느낌으로 재고 발주합니다." (B) |
| 어느 병원 처방이 많이 오는지 알고 있습니까? | "이 소아과가 많은 것 같은데, 정확히 몇 %인지는 모릅니다." (A) |
| 기존 청구 프로그램의 한계는? | "건보 청구만 됩니다. 경영 분석 기능은 없어요." (C) |
| AI 경영 요약 기능을 쓰겠습니까? | "매달 요약해준다면 당장 쓰겠습니다." (C) |

**도출된 핵심 인사이트:**
1. 약사 3인 전원: 현재 통합 경영 분석 불가능 상태
2. 약사 3인 전원: 감에 의존한 재고 발주 중
3. AI 요약 기능에 대한 수요 확인 (즉각 도입 의향)

## 3. 경쟁 제품 심층 분석

### 카테고리 1: 전문 청구 프로그램

**대표 제품:** 비*소프트, 유*케어, 비*약사, 팜*클

**강점:**
- 건강보험 청구 자동화 (핵심 기능)
- DUR(의약품 안전사용 서비스) 연동
- 약국 업무 프로세스에 깊이 통합

**약점 (경영 BI 관점):**
- 청구 목적의 데이터만 저장 — OTC 매출, 발주 데이터 연계 없음
- **경영 분석 기능 전무** — 매출 추이, 병원 의존도, 수익성 분석 불가
- 설치형 Windows 프로그램 — 원격 접근 불가, 모바일 지원 없음
- 높은 비용: 월 15~30만원 + 초기 설치비 + 연간 유지보수비
- 데이터 내보내기 제한 — CSV 추출 불편, 엑셀 연동 수동

### 카테고리 2: 엑셀/구글시트

**강점:**
- 무료, 커스터마이징 자유

**약점:**
- 데이터 통합 불가: 청구/POS/발주 3개 시스템에서 수동 복사-붙여넣기 필요
- 월 3~4시간 소요, 오류 발생 빈번
- 실시간성 전무
- 차트 생성 숙련도 필요
- **결국 대부분 포기** → 데이터 관리 공백 발생

### 카테고리 3: 약국 경영 특화 BI 솔루션

**현황: 국내에 전무** (2026년 3월 기준)

의원·병원용 EMR 연동 BI(닥터앤서, 히포크라테스 등)는 존재하나 약국 특화 지표 미제공:
- 조제약 vs OTC 매출 비중 분석
- 처방전 의료기관별 의존도 분석
- 도매상별 발주 지출 분석

→ **PharmSight AI가 이 공백을 처음으로 겨냥**

### 경쟁사 가격 비교 상세

| 항목 | 청구 프로그램 (비*소프트/유*케어) | 엑셀/구글시트 | 병원용 BI (닥터앤서 등) | **PharmSight AI** |
|------|-------------------------------|-------------|---------------------|-------------------|
| 초기 도입비 | 50~100만원 (설치+교육) | 0원 | 200~500만원 (커스터마이징) | **0원** (브라우저 접속) |
| 월 구독료 | 15~30만원 | 0원 | 30~100만원 | **3~5만원** (목표) |
| 연간 유지보수 | 30~50만원 | 0원 | 별도 계약 | **포함** |
| **연간 총비용 (TCO)** | **280~460만원** | **0원** (시간 비용 별도) | **560~1,700만원** | **36~60만원** |
| 숨은 비용 | PC 교체 시 재설치비 | 약사 시급 환산 월 3~4시간 = 연 150~200만원 | 약국 데이터 미지원 → 사실상 사용 불가 | 없음 |

**가격 산정 근거:**
- 청구 프로그램: 비*소프트 월 20만원대, 유*케어 월 15만원대 (약사 인터뷰 + 업체 공개 요금 기준, 2026년 3월)
- 엑셀 시간 비용: 약사 평균 시급 4~5만원 × 월 3~4시간 = 월 12~20만원 기회비용
- 병원용 BI: 닥터앤서 월 50만원~, 히포크라테스 BI 모듈 월 30만원~ (의원 기준, 약국 미지원)
- PharmSight AI 목표가: Supabase + Render + Gemini API 무료 티어 운영 → 인프라 비용 최소화로 월 3~5만원 구독 가능

**PharmSight AI 가격 경쟁력 핵심:**
- 청구 프로그램 대비 **1/5~1/8 비용**으로 경영 분석 기능 추가 제공
- 엑셀 대비 **시간 비용 95% 절감** (월 3~4시간 → 5분)
- 병원용 BI 대비 **1/10 비용** + 약국 전용 지표 제공 (조제약/OTC 비중, 처방 기관 의존도)
- 초기 도입비 0원 → 약국 디지털 전환 진입 장벽 최소화

## 4. 시장 규모 (TAM/SAM/SOM)

```
TAM (전체 시장)
└─ 국내 약국 25,000개 × 월 SaaS 구독료
   → 연간 수천억 규모 잠재 경영 도구 시장

  SAM (서비스 가능 시장)
  └─ 디지털 전환 의향 약국 ~8,000개 (전체의 32%)
     → 보건복지부 '약국 디지털 전환 지원 사업' 참여 의향 조사 기준

    SOM (초기 목표 시장)
    └─ 수도권 얼리어답터 약사 ~500개
       → AI 기능 수용성 높음, 변화에 적극적인 개국 5년차 이하 약사 집중
```

## 6. PharmSight AI 포지셔닝 맵

```
           경영 인사이트 수준
                 높음
                  │
    PharmSight AI ●
                  │
─────────────────────────────── 접근성
낮음              │              높음
                  │
    EMR 연동 BI ●  │
    (병원용)       │
                  │   ● 청구 프로그램
                  │   (약국용, 설치형)
                 낮음
```

- 청구 프로그램: 약국 특화 + 접근성 낮음 + 경영 인사이트 거의 없음
- 병원용 EMR BI: 경영 인사이트 높음 + 약국 미적합 + 고비용
- **PharmSight AI: 약국 특화 + 브라우저 기반(접근성 높음) + 경영 인사이트 높음**

## 6. 경쟁사 직접 사용 검증

### 검증 목적

경쟁 제품이 실제로 약국 경영 분석 기능을 제공하지 않는지를 **직접 사용하여 확인**했습니다.

### 검증 대상 및 결과

#### (1) 비소프트 (건보 청구 프로그램)

| 항목 | 검증 결과 |
|------|----------|
| **접근 방식** | 비소프트 공식 홈페이지 데모 화면 + 약사 A의 실제 사용 화면 확인 (인터뷰 중) |
| **제공 기능** | 처방전 입력, 건강보험 청구서 생성, DUR 의약품 안전사용 서비스 연동 |
| **경영 분석 기능** | **전무** — 매출 추이 차트, 병원별 의존도 분석, 도매 지출 비교 등 일체 없음 |
| **데이터 내보내기** | 청구 내역 CSV 추출 가능하나, 경영 분석용 집계 기능 없음 (수동 엑셀 작업 필요) |
| **모바일 접근** | 불가 — Windows 설치형 프로그램 |
| **결론** | 건보 청구 전용 도구. 약국 경영 분석 BI 기능 부재 확인 |

#### (2) 유케어 (건보 청구 프로그램)

| 항목 | 검증 결과 |
|------|----------|
| **접근 방식** | 유케어 공식 홈페이지 기능 소개 페이지 + 약사 B의 사용 경험 청취 |
| **제공 기능** | 처방전 조제, 건강보험 청구, 재고 관리 (입출고 수량 기록) |
| **경영 분석 기능** | **전무** — "통합 매출 분석" 메뉴 없음, 처방전 기관별 집계 불가 |
| **재고 관리** | 입출고 수량 기록만 가능 — 금액 기반 도매상별 지출 비교 불가 |
| **모바일 접근** | 불가 — Windows 설치형 프로그램 |
| **결론** | 청구 + 기초 재고 관리만 제공. 매출-지출 연결 분석, AI 요약 기능 부재 확인 |

#### (3) 엑셀/구글 시트 (수동 관리)

| 항목 | 검증 결과 |
|------|----------|
| **접근 방식** | 약사 C의 실제 엑셀 파일 확인 (인터뷰 중, 개인정보 제거 상태) |
| **실제 사용 상태** | 월별 매출 합계를 수동 입력 — 3개 시스템 데이터 복사-붙여넣기 |
| **소요 시간** | 월 3~4시간 (약사 본인 측정) |
| **분석 수준** | 단순 합계만 가능 — 병원별 의존도, 연령대 분포 등 교차 분석 불가 |
| **AI 기능** | 없음 |
| **결론** | 시간 비용 높고 분석 수준 낮음. 대부분 중도 포기 (인터뷰 3인 중 2인 "포기했다" 응답) |

### 검증 요약

| 경쟁 제품 | 약국 경영 BI 기능 | PharmSight AI 대비 |
|----------|-----------------|-------------------|
| 비소프트 | 없음 (청구 전용) | PharmSight가 **유일하게** 매출-처방-지출 통합 분석 제공 |
| 유케어 | 없음 (청구 + 기초 재고) | PharmSight가 **유일하게** AI 경영 요약 + 시각화 제공 |
| 엑셀 수기 | 제한적 (수동 합계) | PharmSight가 **자동화**로 월 3~4시간→5분 단축 |

> **결론:** 국내 약국 대상 경영 분석 BI 도구는 **2026년 3월 현재 존재하지 않음**을 직접 사용 및 인터뷰를 통해 검증 완료.
